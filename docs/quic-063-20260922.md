# QUIC 0.63 dependency update and repository boundaries

The Tailcat application remains exclusively in `LiuTangLei/tailcat-quic`.
This branch upgrades its shared protocol library to the public immutable
`LiuTangLei/quic-go v0.63.0-tailscale.1` tag, commit
`658bc72e5bcd0754d38d79308f6b869cea16959e`. Despite the compatibility tag's
suffix, the library is usable by both applications; it contains no Tailcat
commands or services.

The existing Tailscale library replacement remains:

```
tailscale.com => github.com/LiuTangLei/tailscale v1.102.3-tailcat.3
```

The new QUIC replacement is:

```
github.com/quic-go/quic-go => github.com/LiuTangLei/quic-go v0.63.0-tailscale.1
```

The old application pin selected `v0.62.0-tailcat.3`. The update preserves its
BBRv3 controller, H3 handshake/exporter, real authenticated reliable stream
transport and acknowledged FIN compatibility API, and adds upstream 0.63
parsing/error/varint fixes. No standard-WG or AWG fallback is introduced.

At inspection time the default `h3-v0.6` branch and existing `v0.6.0-h3.3`
release use the original libraries. The separate
`isolate-transport-release-20260919` branch is the one pointing at the
September 19 `tailcat-tailscale` / `tailcat-quic-go` full-library mirrors.
This upgrade does not adopt those mirrors. Splitting application ownership
does not require maintaining duplicate copies of a generic QUIC library.
Do not delete a historical mirror while another branch or tag still pins it.

This application still uses low-level Tailscale library facilities. Moving
custom H3 integration into an application-owned or small reusable module would
be a separate refactor, not a repository rename or deletion. No such refactor
or mirror removal is claimed by this dependency update.

Verification: the complete short-mode Tailcat test suite, including CLI and
web packages, passed first with the merged source and then with the public
source tag using `-mod=readonly`. The QUIC library's own short/race suites and
the Tailscale consumer's H3 authentication tests also passed. Existing H3
request binding remains valid with 0.63's URL representation and wrapped error
changes. This is not a new WAN speed claim, production rollout or binary release.
